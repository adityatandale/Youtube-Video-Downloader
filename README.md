# Youtube-Video-Downloader

A GUI-based YouTube Video Downloader built using Python and `yt-dlp`.  
This application allows users to download YouTube videos in the highest available quality using a simple interface.

---

## Features

- Download YouTube videos easily
- Simple and beginner-friendly GUI
- Choose custom download folder
- Downloads best available quality
- Fast and reliable using `yt-dlp`
- Error handling for invalid links

---

## Technologies Used

- Python
- tkinter
- yt-dlp

## Installation

### 1. Clone the Repository

```bash
git clone https://github.com/your-username/youtube-video-downloader.git
```

### 2. Navigate to the Project Folder

```bash
cd youtube-video-downloader
```

### 3. Install Required Libraries

```bash
pip install -r requirements.txt
```

Or install manually:

```bash
pip install yt-dlp
```

---

## Run the Project

```bash
python main.py
```

---

## How to Use

1. Open the application
2. Copy a YouTube video URL
3. Paste the URL into the input field
4. Click the **Download Video** button
5. Select a folder to save the video
6. The video will start downloading automatically
